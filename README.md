# Yield Bridge — Sovereign & Safe Yield Navigator

**Yield Bridge** is an interactive web application designed to help households and micro-investors compare Indian government sovereign schemes against standard savings accounts and Micro-SIPs. It calculates your 'Inaction Tax' and connects you to safe, high-yielding government schemes.

---

## Key Features
* **Documentation & Onboarding Guidance:** Provides clear documentation requirements and step-by-step branch visit guides to apply for each scheme.
* **Smart Scheme Recommendations:** Recommends optimal schemes based on age and gender (e.g., Sukanya Samriddhi Yojana (SSY) for girl children under 10 years, Senior Citizen Savings Scheme (SCSS) for retirees, etc.).
* **Comprehensive Scheme Comparisons:** Provides direct comparisons between schemes across lock-in periods, tax benefits, and minimum entry requirements.
